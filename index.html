Formulario → Dashboard (HTML puro)

Demo: comunicación entre dos páginas usando solo HTML, método GET, sin JavaScript ni backend.

Formulario

Truco: el form usa method="GET" y target="dashboard-frame", así carga el resultado dentro del iframe pasando los datos en la URL como ?nombre=…&rol=….

Dashboard (iframe)

Fíjate en la URL del iframe al enviar: contiene los parámetros enviados por GET. Sin JS/backend, el HTML no puede "leer" esos parámetros para renderizarlos dinámicamente — por eso se usan páginas estáticas predefinidas (ver README).
